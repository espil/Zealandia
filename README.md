# Espil Online: Zealandia Edition

Espil Online is, at its base, a community and a free knowledge, information and skill sharing solution. Zealandia is where that community takes its game form: the paid MMORPG app layer, set on the sunken continent under New Zealand, risen again as a crafted game world.

## The world model

• The continent map is a travel layer only: the drained Zealandia map moves the player between places (teleport / skip)
• Zealandia's places are crafted, not generated: Plushy AI creates the 2D buildings, Meshy AI builds them into 3D
• Real-world cities (Vancouver, Auckland, and the rest) run on the older generated-building mechanism, retrieved and documented in docs/old-building-generation-protocol.md
• Trading between players and the Leo Coin economy are core axes, with a proper MMORPG backend behind the app

## Repository map

• `docs/` - the v1 build plan, the architecture + UI/UX package (docs/zealandia-architecture-uiux/), the old building generation protocol, the enemy pack tuning brief, the store listing decision pack, and reference captures
• `map-data/` - the released-data terrain package: GMRT-sourced elevation grids for the whole continent, the Auckland zone, and the Queen Street corridor, with the build scripts that made them. Elevation sources and validation are documented in map-data/README.md. The NIWA TIFF exports that failed integrity checks are documented there and archived locally; they are not in this repo
• `app/` - the Capacitor app (appId online.espil.zealandia): config, the web sync script, the Android / iOS projects, and the playable payload in `app/www/`

## App payload and running the app

The playable web payload is committed in `app/www/` (Han's decision, 2026-10-21), so the app runs from a fresh clone on both platforms:

• `cd app && npm install`
• `npx cap sync` - copies www into the native projects (the `public/` copies inside the Android / iOS projects are generated by this step and stay out of git)
• `npm run serve` - try it in a browser
• `npm run android` - opens the Android project in Android Studio
• `npm run ios` - opens the iOS project in Xcode. Building for iPhone requires a Mac with Xcode (Apple's rule); the project, config, and payload are identical to Android's

The payload itself is a hybrid: the current espil.online testing UI over the revived textured-facade building generation, plus the first Zealandia town (Auckland region, real drained terrain, enterable buildings, villagers, monsters, combat). It is assembled from the staged Espil build sources by `app/scripts/sync-web.mjs` whenever it is regenerated.
