# Village assets - KayKit Medieval Hexagon Pack (CC0)

The built village in Waitemata (ztown.js, buildVillageAssets) uses
models from the KayKit Medieval Hexagon Pack 1.0 by Kay Lousberg:

• village_well, village_market, village_blacksmith, village_chapel,
  village_tavern, village_windmill, village_lumbermill,
  village_home_a, village_home_b, village_tower (blue building set)
• village_tree_a, village_tree_b, village_rock_a, village_rock_b
  (nature set)
• village_barrel, village_crate, village_sack, village_wheelbarrow,
  village_tent, village_weaponrack (props set)

License: CC0 - free for personal and commercial use, no attribution
required (per the pack's itch.io page and the Godot Asset Library
entry). This note is kept for provenance, not because the license
demands it.

Provenance (2026-10-23): the pack was selected on its itch.io page
(kaylousberg.itch.io/kaykit-medieval-hexagon). itch.io's download
endpoint refused direct fetches from this machine (token POST plus
a 429), so the identical pack was fetched from the author's
official GitHub mirror (KayKit-Game-Assets/KayKit-Medieval-Hexagon-
Pack-1.0, the same 2024-04-26 release) and the chosen glTF models
were converted to single-file GLB with gltf-pipeline. Working files:
~/workspace/zealandia-village-assets/ (zip, extracted pack, GLBs).
