스프라이트 팔레트

팔레트에서 고른 뒤 지도를 클릭하면 배치됩니다. 연속으로 찍을 수 있고, Esc를 누르면 해제됩니다.

사용법

• 화면 이동: 스페이스+드래그, 마우스 가운데/오른쪽 드래그, 또는 이동 도구
• 확대/축소: 마우스 휠 (커서 위치 기준)
• 타일: 타일 도구로 클릭/드래그
• 스프라이트: 선택 도구로 드래그 이동, Delete 키로 삭제
• 구역: 스폰 구역 도구로 드래그해 사각형 그리기
• 모든 변경은 자동 저장됩니다 (브라우저 localStorage)
